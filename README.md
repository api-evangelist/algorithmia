Algorithmia provides a platform that enables developers to discover, share, and run algorithms at scale via a simple API. Founded in 2013, it offered a marketplace for AI models and a cloud-based execution environment. In 2021, Algorithmia was acquired by DataRobot, and its services have been integrated into the DataRobot AI Platform. The original website now redirects to DataRobot, reflecting the transition.

**Areas:** Artificial Intelligence · Machine Learning · Marketplace · Platform · DataRobot
